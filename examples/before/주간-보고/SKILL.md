# 주간 보고

> 이 스킬은 skill-structure-check 의 예시로 지어낸 가짜다. 이름, 명령, 수치는 모두 지어냈다.

한 주 동안 쌓인 일 기록을 모아 금요일 오후에 팀장에게 보내는 주간 보고를 쓴다.

## 절차

### 1. 자료 모으기

일 기록 파일(`기록/이번주.csv`)에서 이번 주 줄 수를 먼저 본다.

```bash
python3 -c "
import csv
rows = list(csv.DictReader(open('기록/이번주.csv', encoding='utf-8')))
print(len(rows), '건')
"
```

그다음 아래 순서로 돌린다.

1. `git -C 기록 pull` 로 기록을 맞춘다.
2. `python3 tools/merge.py 기록/이번주.csv` 로 겹친 줄을 합친다.
3. `python3 tools/summary.py --week` 로 요약표를 만든다.
4. `python3 tools/send.py --to 팀장 요약.md` 로 요약표를 보낸다.

### 2. 결과 읽기

| 결과 | 뜻 | 할 일 |
|---|---|---|
| `OK` | 빠진 날 없음 | 3으로 간다 |
| `MISSING n` | n일 기록이 빔 | 그날 담당자에게 묻는다 |
| `DUP n` | 같은 줄이 n개 | 1의 2번 명령을 다시 돌린다 |

### 3. 보고 쓰기

마감은 금요일 18시다. 마감까지 남은 기간을 며칠로 계산해 첫 줄에 적는다.

보고는 아래 모양 그대로 채운다.
```markdown
# <팀 이름> 주간 보고 (YYYY-MM-DD)

- 한 일: <세 줄 안>
- 다음 주: <세 줄 안>
- 막힌 것: <없으면 '없음'>
```

## 시험 기록

- 2026-01-09 요약표 명령을 처음 돌림. 45건, 빠진 날 없음.
- 2026-01-16 `DUP 3` 이 나와 합치기 명령을 다시 돌림. 그 뒤 `OK`.

## 배운 것

- 2026-01-16 합치기 전에 요약표를 만들면 같은 일이 두 번 들어간다. 순서를 지킨다.
